Wikster logo concepts

Four new marks drawn by hand on a 64 unit grid, flat colour, no effects. Each one has a detailed cut for 48 px and up and a simpler cut for small sizes, a one colour version, an app icon and a geometric wordmark built from the same stroke. Every colour version takes the theme tint through --logo-inner and --logo-outer, like the crest does today.

Swapping it

The game uses Hand. One line in src/data/logo.js picks the mark: import { fan as LOGO } from './logos/fan.js';. The menu, sign in, splash, PC shell, intro, favicon and store art follow it. Then node tools/icons.mjs (web icons and the favicons of the static pages) and node tools/desktop-icons.mjs (Tauri). The Android launcher, themed and notification icons come from node tools/android-icons.mjs, which draws the Hand from its geometry in src/data/logos/fan.js.
